# 🪼 MEDUSA

### A playful network observer for Windows

**MEDUSA** is a desktop application currently in development, designed to make network activity easier to understand and more visual.

It monitors connections, ports, processes, and network traffic in real time, presenting the data through an ocean-inspired interface with an animated mascot that reacts to system activity.

> 🌊 **See what moves beneath your network.**

---

## ✨ Current Features

- 🔌 Monitoring of ports and services such as **HTTPS, DNS, SMB, RDP, and SSH**
- 🖥️ Identification of the **process** associated with each connection
- 🌐 Display of **local and remote IP addresses**
- 📡 Real-time **download/upload traffic**
- 🔎 Detailed connection view by clicking on a monitored port
- 🕒 History of new connections observed during the last **60 seconds**
- 🧵 Network scanning performed in a separate thread from the GUI
- 🪼 Animated MEDUSA mascot with **CALM, ACTIVE, SUSPICIOUS, and CRITICAL** states
- 🫧 Ocean-themed elements and animations integrated into the interface

---

## 🚧 Project Status

MEDUSA is still in the early stages of development.

The goal is to gradually turn it into a **network visibility and security monitoring** tool that is easy to understand, even for users who are not networking experts.

The `SUSPICIOUS` and `CRITICAL` states are currently used mainly to control the mascot's visual behavior and **do not yet represent actual security verdicts**.
